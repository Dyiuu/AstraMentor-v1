# 项目8：交付可评测的职业课程知识助手

## 岗位情境

学院要求交付一个“AI 实训安全与课程规范助手”MVP。学生按自然语言提问，系统只从当前课程有效材料检索，返回带章节或页码的依据；资料不足时会拒答并建议澄清。课程负责人还要求文档更新后能只重建受影响索引，评测报告证明无跨课程与越权混入。你作为 RAG 项目负责人，需要把需求、文档、切分、索引、混合检索、依据生成和评测组合成可运行交付包。

综合项目以单知识库问答服务为边界，不引入自主规划、多 Agent 或自动执行外部工具。索引是可再生成产物，Markdown/PDF 与来源清单才是事实源。

## 项目目标

- 能以数据契约连接来源登记、Document、Chunk、索引、SearchHit、GroundedAnswer 和评测结果。
- 能实现课程、版本、生效状态和权限全链路隔离，材料变更触发对应索引 stale。
- 能提供 BM25 本地基线、可选向量、RRF、重排降级、带引用答案与正确拒答。
- 能暴露构建状态、查询 trace、用量、延迟和错误，但不记录敏感正文。
- 能通过自动化、盲验、故障演练和 30 问报告完成岗位交付。

## 项目产物与验收条件

产物为知识库服务、课程材料清单、构建/查询 CLI、索引目录、测试与运行手册。

- [ ] 输入当前 course_id、身份和 query，输出只来自该课程允许材料的 SearchHit 或 GroundedAnswer。
- [ ] 每条引用含课程、文档、章节、路径与行/页；source_path 可安全解析且原文件存在。
- [ ] missing/stale/failed 索引不调用模型、不切换其他课程，返回可操作状态；ready 无可靠证据时明确拒答。
- [ ] 30 问评测满足批准阈值，越权/跨课结果为零，高风险错误答案为零，P95 和用量在预算内。
- [ ] 验收证据包括干净环境重建、索引 manifest、测试报告、逐问结果、五次引用抽查、故障恢复与同伴盲验。

## 任务分析

### 岗位任务、输入与输出

输入包括批准语料、课程 manifest、用户角色、查询、索引配置、模型配置和评测数据；输出包括版本化索引、查询响应、CitationLedger、指标与运行状态。构建路径和查询路径分开：构建可耗时并产出新版本，查询只能读取已经完整验收的 ready 版本。

可复现实训使用本课程自编材料和固定 30 问，默认禁用远程 embedding，只用本地 BM25 建立可重复基线；固定向量与模型桩验证混合和答案流程。可选真实模型运行单独标识，不改变离线验收结论。新同伴在清空生成索引后，依手册重建并抽查五条引用。

## 核心知识

### 两条流水线与一个版本边界

构建流水线是 source → Document → Chunk → lexical/vector index → manifest → self-check → publish；查询流水线是 identity/query → filters → retrieve → fuse/rerank → assemble → generate/validate → respond。查询读取同一 `index_version` 的所有文件，不能把新向量与旧映射混用。发布通过原子 current 指针切换，失败构建不影响上一个可用版本。

### 课程隔离和状态

course_id 从入口贯穿来源根、manifest、索引目录、检索过滤、引用与学习记录。目录名必须经过安全 ID 校验，不能让请求构造任意路径。状态至少有 missing、building、ready、stale、failed。非 ready 课程返回结构化冲突，让界面提示构建或重试；绝不自动借用另一门课索引，也不跳过 RAG 调模型。

### 证据不足与扩展内容

ready 只说明索引与材料一致，不保证每个 query 有答案。检索为空或证据不能支持关键主张时返回 insufficient_evidence。若产品未来允许模型扩展知识，必须在独立模式和响应字段中显著标识，不能给教材引用外观；本综合项目默认关闭扩展，以便职业课程答案边界清晰。

### 可维护交付

新增或更新材料时先验证 manifest 路径、结构、来源和密钥，再判断源 checksum 使单课 stale。构建日志记录各阶段数量、耗时、警告和失败文档。运行手册包含首次构建、状态查看、查询、重建、回滚和数据删除。索引文件不可手工编辑，任何修复回到源或配置后重建。

## 工程实现步骤

1. 固化课程 manifest、来源登记和 30 问版本；验证所有路径位于课程根、材料非空且无未授权数据。
2. 依次运行解析、结构切分、BM25 与可选向量构建，每阶段输出数量、checksum、警告和隔离结果。
3. 在临时版本目录保存索引、映射与 manifest，加载自检 course、数量、维度和 source checksum，再发布 ready。
4. 查询入口验证 course_id 和身份，打开该课程 current 版本；应用版本、生效、权限过滤并执行双路召回。
5. 用 RRF、近重复去除和可选重排形成候选；重排失败回退，检索证据不足直接结构化拒答。
6. 组装请求内 Ledger，生成并校验 GroundedAnswer；正式响应从 Ledger 渲染引用，记录状态与非敏感 trace。
7. 跑 30 问与路径/权限/损坏/更新测试，逐问归因。失败门槛先修数据或检索，不通过改题掩盖。
8. 清空生成目录做干净重建，让同伴按手册完成五问、一次材料更新、一次 failed 回滚和五条引用抽查。

## 关键代码与配置

查询门禁在任何检索或模型调用之前执行。

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class IndexState:
    course_id: str
    status: str
    version: str | None

def require_ready(state: IndexState, requested_course: str) -> None:
    if state.course_id != requested_course:
        raise ValueError("索引课程与请求课程不一致")
    if state.status != "ready":
        raise RuntimeError(f"course_index_not_ready:{state.status}")
```

```text
rag/indexes/rag-knowledge-engineering/
```

`current` 只在版本目录全部写入并通过自检后切换；Windows 环境可用小型 current 元数据文件配合原子替换实现同样语义。

## 调试和常见故障

### 故障案例一：课程索引 stale 时系统仍调用通用模型

- **现象：** 材料修改后查询返回流畅答案却没有引用，调用日志显示模型已执行。
- **原因：** 路由在检索异常时捕获所有错误并降级为“无 RAG 聊天”，违反课程证据边界。
- **定位：** 注入 stale 状态，检查 retriever/model mock 调用计数；模型计数本应为零。
- **修复：** 在查询最前执行 ready 门禁，返回 `course_index_not_ready` 与当前状态；只有 ready 才进入检索和生成。

### 故障案例二：更新一门课使全部课程不可用

- **现象：** 修改本课程一个 Markdown 后，其他课程状态也变 stale，首页要求全部重建。
- **原因：** 全局 checksum 包含所有课程材料，状态没有按 course_id 分区。
- **定位：** 比较各课程 manifest 的 source 列表，发现共同使用一个总哈希；检查索引目录映射。
- **修复：** 每课独立计算来源 checksum 和索引状态，只标记受影响 course；公共代码版本变化才按兼容策略批量重建。

### 故障案例三：引用路径可以逃出课程目录

- **现象：** 恶意 manifest 的 `../` 路径被索引，引用接口能够读取课程外文件。
- **原因：** 只做字符串拼接，没有解析绝对路径并验证允许根。
- **定位：** 用临时目录创建越界 manifest，检查注册与构建是否拒绝；审计 source_path 解析结果。
- **修复：** 课程 ID 使用安全格式，材料路径 resolve 后必须是课程根后代；无效课程隔离且不影响兄弟课程。

## 安全、成本与职业规范提示

检索前的课程和权限隔离是硬边界，提示中的“只回答本课程”不能替代它。索引、日志、评测集和缓存均是源数据派生物，备份、删除与权限需要一致。错误响应不暴露系统绝对路径或受限来源名称。教材中的命令只作为文本证据，不可触发执行。

离线 BM25 保证最低可运行性；远程 embedding、重排与生成按授权和预算开启，并记录实际 usage。重建只针对变化课程降低费用，但不能跳过 manifest 自检。交付报告必须公开扫描件、表格、OCR、语料覆盖和样本量限制，不用“30 问全过”推断所有问题都正确。

## 实训练习

1. 从空索引目录执行构建，保存每阶段数量、manifest 与 current；重启后五问结果可复现。
2. 修改一份材料，验证只有本课程 stale，且 stale 查询的模型 mock 调用为零；重建后恢复 ready。
3. 注入越界路径、损坏映射和重排超时，分别验证课程隔离、回滚与 RRF 降级。
4. 跑 30 问生成逐问与聚合报告，抽查五条引用回到源行/页，任何越权和跨课结果必须为零。
5. 邀请同伴依文档完成清空重建、查询、拒答和回滚；提交其命令记录、问题、修订与最终签收。

## 本项目小结

职业课程知识助手的价值来自完整证据链，而不只是聊天界面。版本化构建保证索引与源一致，课程和权限门禁保证隔离，混合检索提高覆盖，Ledger 与拒答控制答案边界，分层评测证明质量和风险。该综合项目形成可独立运维的 RAG 服务；在后续 Agent 课程中，它只作为已经受控的知识工具接入，不重复教授切分与检索实现。
